# 参与贡献

[English](/en/reference/contributing)

learn-pi 的目标是用一套 TypeScript 实现教会读者扩展真实 Pi。改动应让某个行为更可解释、可运行或可验证，而不是增加互不相关的演示。

## 本地开发

使用 Node >=22.19.0，运行 `npm ci --ignore-scripts`。`npm run verify` 检查类型、测试和双语文档；`npm run test:integration` 验证真实 Pi/MCP 接线；`npm run demo` 重现脚本化模型驱动的实际工具闭环。`npm run docs:dev` 启动仅本机可见的预览。

## 改动约定

- 主代码在 `src/`，可丢弃练习从 `examples/fixtures/` 复制，不把实验修改反写到基础 fixture。
- 章节中文在 `docs/chapters/`，英文在 `docs/en/chapters/`；相同路径保持内容与导航对等。
- 修改工具契约时同步 schema、策略分类、失败测试、两种语言的命令与边界说明。
- 测试断言可观察行为，不只匹配实现字符串。Mock 只控制模型输入或故障，不替代真实 Pi/MCP 集成。
- 修改依赖前核验已发布版本、npm `gitHead`、对应源码和许可证，更新锁文件与来源页。不要混用 `main` 和发布包 API。
- 新增扩展默认视为宿主代码。说明凭据、网络、文件和执行权限；不要把应用钩子叫沙箱。

## 提交与评审

围绕一个可审查问题提交，说明触发条件、改动后行为、验证命令和未验证边界。页面文字或低影响样式调整不必新增镜像测试，但要构建并查看相关页面。不要提交认证数据、`.cache/`、生成的样例工作区或 `node_modules/`。

本地 Git 提交可以用于记录进度；公开仓库、远端推送、网站部署和社媒发布必须有单独授权。本项目当前交付范围为本地验收。
